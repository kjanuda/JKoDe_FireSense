# FireSense Independent Validation Data Request v0

## Target

FireSense is seeking independent experimental data for validation of a
reduced-gravity PMMA flame-spread baseline.

The target condition is:

- Material: PMMA
- Geometry: thin sheet
- Nominal thickness: 200 µm / 0.2 mm
- Oxygen concentration: 21 vol.%
- Pressure: approximately 101.3 kPa
- Gravity: true microgravity
- Flow configuration: opposed flow
- Flow velocity: 50 mm/s
- Quantity: flame spread rate
- Preferred unit: mm/s
- Preferred minimum: 3 independent experimental runs

## Required provenance

For each usable observation, FireSense requires, where available:

- run or experiment identifier
- specimen thickness
- oxygen concentration
- pressure
- gravity level / facility
- opposed-flow velocity
- measured flame-spread rate
- uncertainty or within-run variability
- measurement method
- source/publication reference

## Scientific use policy

The requested data will be treated as holdout evidence.

It will not be used to train or refit the FireSense baseline model.

Digitization uncertainty, experimental uncertainty, and model uncertainty
will remain separate.

A condition that differs from the target will be retained as comparison
evidence rather than labelled direct validation evidence.

## Specific questions for the data provider

1. Were 0.2 mm PMMA specimens tested in true microgravity?
2. Were tests conducted near 21 vol.% O2 and 101.3 kPa?
3. Were any of those tests conducted at 50 mm/s opposed flow?
4. Were multiple independent drops/runs performed at that condition?
5. Are numerical flame-spread-rate values available for those runs?
6. Are run-level uncertainty or variability values available?
7. Can the raw or processed numeric data be shared for research validation?
